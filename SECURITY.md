# Security Policy

## Supported Versions

Security updates are provided for the current major release line:

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |
| < 2.0   | No        |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Instead, report vulnerabilities privately using one of the following channels:

- **GitHub Security Advisories**:
  https://github.com/prabothcharith/accessibility-plugin-react/security/advisories/new
- **Email**: probothcharith@gmail.com

Please include as much of the following information as possible:

- Package version (`accessibility-plugin-react`) and React/Next.js version
- Affected component, controller, or API
- Clear steps to reproduce or a minimal proof of concept
- Potential impact (e.g., XSS, CSS/style injection, DOM clobbering, storage tampering)

## Response Workflow

1. Reports are acknowledged as soon as possible by the maintainer.
2. Confirmed issues are investigated, reproduced, and patched in a private fix
   before public disclosure.
3. Once a fix is released, an advisory and changelog entry will be published
   crediting the reporter if desired.
